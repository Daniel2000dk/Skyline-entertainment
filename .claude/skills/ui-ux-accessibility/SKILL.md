# Ui Ux Accessibility

Make public signup one field and one main CTA; internal dashboards task-first. Dutch UI, accessible contrast/focus/keyboard controls, responsive layouts, clear empty/loading/error states. Prefer simple coherent components; avoid vanity animations, unnecessary settings and excessive navigation.
